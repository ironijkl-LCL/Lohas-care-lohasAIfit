# 樂活健康管理系統 (Lohas GeronTech Clinical)

專為香港安老院舍設計之長者臨床膳食、IDDSI 吞嚥防線與水分管理系統。

## 🌟 核心功能
- **IDDSI 雙向安全檢驗**：自動比對食物硬度與流質稠度，超標立即攔截。
- **AI 嗆咳與流速即時偵測**：動態光流演算法量測餐盤流質稠度，預警稀薄流質嗆咳危險。
- **Lohas Copilot 臨床推理**：即時分析長者過敏原、熱量缺口並推薦專屬飲食處方。
- **免手持離線語音**：支援本機「記錄水分 200」指令，廣東話即時播報。
- **A4 醫療交班單**：支援瀏覽器一鍵列印標準臨床巡房交班報告。
