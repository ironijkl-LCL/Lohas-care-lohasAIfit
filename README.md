## 📱 關於樂活飲食

樂活飲食係一款專為大眾設計嘅個人健康飲食日誌。我哋支援：

*   📸 **影相辨識**：自動分析餐盤營養與質地
*   🎙️ **自然語言記錄**：一句話自動拆解餐點
*   📊 **19 項微量營養素**：精準追蹤熱量、蛋白質、鈉、鉀、鈣等
*   ⚖️ **體重與水分追蹤**：每日達標進度一目了然
*   🔒 **私隱優先**：所有資料優先加密儲存於用戶手機本地
